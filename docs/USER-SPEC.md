# hlens · 用户视角的功能与显示定义（v2，与 PRODUCTION-SPEC 并列，页面以本文为准）

> 写法：先说用户在什么时刻带着什么问题打开网站，再定义那一页显示什么、第一句话说什么、图表证明什么、手机上怎么看。技术实现见 `PRODUCTION-SPEC.md`。
> 原则：每一页回答一个问题；第一屏第一行是人话答案；图表只用来证明那句话；一切数据可切换到"相对于我的仓位"；不放广告；手机优先。

---

## 0. 我们凭什么被访问

| 用户的抱怨（对 Coinglass 类站点） | hlens 的回答 |
|---|---|
| "一堆图，我不知道该看哪张" | 六个问题六个页面，第一行就是答案，证据在下面 |
| "这些数据和我的仓位没关系" | **我的仓位模式**：本地输入仓位，全站数据变成相对于你的 |
| "看完了，然后呢？" | 每个数字后面跟一句"所以"，并标注是已验证、启发式还是观点 |
| "广告、弹窗、登录墙" | 无广告；核心功能不登录；登录只为告警和保存 |
| "手机上根本没法用" | 手机优先设计，底部五键，单手可用 |
| "看不出谁在骗我" | 公开记分板：我们自己的信号命中率公开滚动，错了也显示 |
| "大户数据只是一张表" | 大户是故事：谁在赌什么、谁快爆了、谁刚认输，可一键分享成卡片 |

## 1. 站点结构（按问题组织）

| 路由 | 问题 | 一句话 |
|---|---|---|
| `/` | **现在怎么样？** | 六张问题卡 + 我的仓位摘要 |
| `/missed` | **我睡觉时发生了什么？** | 过去 8 / 24 小时的事件时间线 |
| `/coin/BTC` | **我是不是来晚了？** | 棱镜：人群在哪边、挤了多少、大户站哪边 |
| `/coin/BTC/levels` | **危险在哪？** | 价格标尺：爆仓堆、大户强平价、你的强平价 |
| `/coin/BTC/cost` | **拿着要花多少钱？** | 费率成本计算 + 换所省多少 |
| `/whales` | **大户在干什么？** | 事件流、赌局板、快爆板、认输板 |
| `/replay` | **当时发生了什么？** | 选一个时间，回放那一刻的全部 |
| `/find` | **今天做哪个币？** | 人话预设筛选，不是 30 列表格 |
| `/alerts` | **帮我盯着** | 按仓位和币种订阅推送 |
| `/method`、`/scorecard` | **凭什么信你？** | 公式、来源、局限、公开命中率 |

底部导航（手机）：现在 · 币 · 大户 · 盯盘 · 我。
"我"= 我的仓位、关注、告警、设置。

## 2. "我的仓位"模式（贯穿全站）

- 入口：顶栏"＋ 我的仓位"。表单四项：币、方向、开仓价、杠杆（可选：金额、止损）。存在浏览器本地，不需要注册；登录后可同步。最多 10 个仓位。
- 开启后全站变化：
  - 每页顶部出现仓位条：币 · 方向 · 开仓价 · 当前盈亏 % · 距强平 % · 今日费率成本 · 一句风险评价（如"人群和你同向且拥挤，费率对你不利"）。
  - 棱镜页：光谱条上标出"你"的位置；"分歧陈述"改为"和你的关系"（大户与你同向 / 反向）。
  - 价格标尺：画出你的开仓价、止损、强平价，与爆仓堆和大户强平价的距离用数字标出。
  - 费率页：直接算你每 8 小时、每天、持有到目标日的成本。
  - 大户页：筛选"和我反向的大户"。
  - 告警：一键创建"我的仓位"套餐：距强平 < 10%、费率对我不利超过阈值、大户反向大额开仓、级联开始、人群反向拥挤度突破。
- 免责：仓位数据只在本地；我们不知道你的账户；这不是交易建议。

## 3. 逐页定义

### 3.1 首页 `/`：现在怎么样？

第一屏（手机一屏放得下）：
1. **一句话市况**（自动生成，带证据标签）：例如"BTC 多头拥挤 +0.31，散户 59% 做多，追踪大户 34% 做多；过去 1 小时爆仓 1200 万美元，多头占 80%。"
2. **六张问题卡**（两列三行）：
   - 我来晚了吗？→ 最拥挤的三个币，各一条拥挤度小条
   - 危险在哪？→ BTC/ETH 距离最近爆仓堆的百分比
   - 大户在干什么？→ 最近三条大户事件
   - 我睡觉时？→ 过去 8 小时三件大事
   - 拿着多少钱？→ 费率最贵和最便宜的三个币
   - 谁快爆了？→ 距强平最近的三个大户仓位
3. **我的仓位摘要**（若已设置）：每个仓位一行。
4. **全市场光谱图**（标志性视觉）：前 30 币各一条竖向光谱，颜色 = 拥挤度，高度 = OI，点击进币页；可"保存为图片"分享。
5. 更新时间与数据源红绿灯。

### 3.2 我睡觉时发生了什么 `/missed`

- 时间范围切换：8h / 24h / 自定义（默认按用户时区的"昨晚 23:00 到现在"）。
- **时间线**（纵向，按时间）：只放五类事件，每类一个图标：
  - 价格：±3% 以上的 15 分钟波动（币、幅度、时间）
  - 爆仓：单币 5 分钟内 ≥ 1000 万美元，或级联事件
  - 费率：8h 口径超过 ±0.05%，或跨所价差 > 0.03%
  - 大户：≥ 500 万美元的开/平/翻转，或大户被强平
  - 人群：拥挤度穿越 ±0.3
- 每条事件：一行标题 + 一行数字 + "当时看"按钮（跳回放）。
- 顶部三句话总结（自动）："BTC 夜间下探 2.4% 后回升；多头爆仓 3800 万美元；两个大户在 76,500 附近加多。"
- 可订阅为每日摘要推送（免费）。

### 3.3 币页：我是不是来晚了 `/coin/[symbol]`

第一屏：
1. **答案句**：三种之一，附拥挤度数值与证据标签：
   - "人群已经很挤了：多头拥挤 +0.42，费率年化 18%，散户 71% 做多。" `启发式`
   - "还不挤：拥挤度 +0.08，费率接近零。"
   - "人群在另一边：空头拥挤 −0.35。"
2. **光谱条**（七行，中心对齐，与 v0.1 一致，加第七行 24h 爆仓多空比）；每行右侧数字；hover/点按显示各所明细与 7 天迷你图。
3. **拥挤度仪表**（−1 到 +1）+ 30 天分位数："比过去 30 天里 87% 的时候都挤"。
4. **人群 vs 大户**一句话 + 与我仓位的关系（若有）。

第二屏：
5. **时序图**：价格 + 可叠加：拥挤度、费率、OI、散户多头、大户净仓位、爆仓柱；默认叠加拥挤度；周期 15m/1h/4h/1d；范围 1d 到 90d。
6. **分交易所表**：价格、费率（原始 / 8h / 年化）、下次结算倒计时、OI、24h 成交、散户多头；最便宜的所高亮。
7. **大户在这个币上**：多空堆叠条 + 前 10 仓位（含距强平 %）。
8. **OI 象限**卡：当前处于"价涨 OI 涨 / 价涨 OI 跌 / 价跌 OI 涨 / 价跌 OI 跌"哪一格，站内统计该格之后 24h 平均收益与样本数 `站内自验证`。
9. 子页入口：危险在哪 · 拿着多少钱 · 回放这个币。

### 3.4 危险在哪 `/coin/[symbol]/levels`

这是 Coinglass 热力图的替代，但用交易者能直接用的形式：**价格标尺**。

- 竖向价格轴，当前价在中间，范围 ±15%（可缩放）。左右两侧标记：
  - 左：**爆仓堆**（模型估算，柱长 = 估算杠杆仓位密度；`模型估算`）
  - 右：**大户强平价**（真实，来自 HL 仓位；点显示钱包与名义）
  - 右：**真实爆仓发生过的价位**（过去 24h，Gate/OKX/Binance/Bybit）
  - 中：**你的开仓价 / 止损 / 强平价**（若设置）
- 顶部答案句："上方 +3.1% 处有约 4.2 亿美元的空头爆仓堆；下方 −2.4% 处有 2 个大户合计 1.8 亿美元的多头强平价。" 附与你仓位的距离。
- 下方：多空爆仓堆合计对比、过去 24h 真实爆仓多空对比、模型假设滑块（杠杆分布权重可调，改动实时重算）。
- 热力图作为第二视图（Tab），给习惯 Coinglass 的人。

### 3.5 拿着要花多少钱 `/coin/[symbol]/cost`

- 输入：方向、金额、持有时长（默认读我的仓位）。
- 输出：每 8h、每天、期间总费率成本，六所各自的成本，"换到 X 所每天省 Y 美元"，历史 30 天该方向累计费率曲线。
- 一句话："过去 30 天做多 BTC 平均每天付 0.02%，最贵的一天 0.15%。"
- 套利提示（`启发式`）：跨所价差扣费后的年化，附执行风险说明。

### 3.6 大户在干什么 `/whales`

四个板块，每个都是"故事"，每张卡可分享成图片（带水印和链接）：
1. **事件流**（实时）：一句话一条："0x5b5d…c060 在 2,271 加空 ETH 5300 万美元，账户 1.03 亿。" 每条 1h/4h/24h 后回填涨跌颜色。筛选：币、类型、最小金额、只看关注。
2. **赌局板**：当前最大的 20 笔仓位：币、方向、名义、开仓价、距强平 %、浮盈亏、杠杆、钱包；按"距强平"排序时就是**快爆板**。
3. **认输板**：过去 24h 大户被强平与大额止损平仓（closed_pnl 为负且 ≥ 100 万美元）。
4. **今日赢家/输家**：按 24h 实现盈亏排。
- 顶部答案句："追踪的 53 个大户净空 40%，过去 24 小时净开空 2.1 亿美元，主要在 ETH。"
- 钱包主页 `/whale/[address]`：账户曲线、当前仓位、历史事件、风格标签（"高杠杆短线 / 低杠杆波段"，站内算法）、该钱包事件的历史命中率、关注与告警按钮。
- **记分板** `/scorecard`：大户开仓 / 平仓 / 翻转之后 1h/4h/24h 的顺向命中率与平均收益，按币和方向分组，滚动 30/90 天，样本数与置信区间可见。首页答案句里引用的"启发式"在这里能查到来源。

### 3.7 当时发生了什么 `/replay`

- 选币 + 选时间（或从时间线、从我的仓位的开仓时间跳入）。
- 显示那一刻的完整棱镜快照（七行 + 拥挤度）、前后 ±6 小时的价格 / 费率 / OI / 爆仓 / 大户事件叠加图、那 6 小时内的事件列表。
- "和现在比"开关：两列并排。
- 一句话复盘（自动，`启发式`）："开仓时多头拥挤 +0.45、费率年化 22%，之后 4 小时多头爆仓 6000 万美元。"
- 可保存为复盘卡片（登录），可导出图片。

### 3.8 今天做哪个币 `/find`

- 不是 30 列表格。先给**人话预设**（点一下出结果，结果每行显示币、当前价、一条迷你光谱、一句为什么入选）：
  - 空头太挤（拥挤度 < −0.3 且费率为负）
  - 多头太挤（拥挤度 > +0.3 且费率年化 > 15%）
  - 大户和散户相反（分歧 > 25 点，样本 ≥ 3 个大户）
  - OI 刚冲高（OI 24h 变化 > 15%）
  - 有人在付钱给你（负费率且跨所价差可套）
  - 大户刚翻转（过去 24h 有翻转事件）
- 高级模式：表格 + 条件组合 + 保存（登录）。
- 每个结果可"加入关注"或"设置告警"。

### 3.9 帮我盯着 `/alerts`

- 三步创建：选对象（我的仓位 / 币 / 大户 / 全市场）→ 选模板（每个模板一句人话，如"当有大户在我反方向开仓超过 500 万美元时"）→ 选渠道（Telegram 主、邮件、浏览器推送）。
- 免费：3 条 + 每日摘要；Pro：50 条实时 + Webhook。
- 消息格式：一句话 + 三个关键数字 + 一张迷你光谱图 + 深链接到"当时看"。
- 投递记录可查；一键暂停全部。

### 3.10 凭什么信你 `/method`、`/scorecard`、`/status`

- 方法：每个指标一张卡：定义、公式、来源、局限、更新频率。
- 证据库：每条"已验证"标签的数据量、期间、方法、效应大小；你的本地研究摘要明确标注样本期和"未在本站复现"。
- 记分板见 3.6。
- 状态页：各源延迟与 30 天可用率。
- 变更日志。

## 4. 显示规范（所有页面）

- **答案在前**：每页第一行是一句话，20 字以内的中文或 25 词以内的英文，后跟证据标签。图表在答案之下。
- **三色**：多头绿、空头红、中性灰；拥挤度轨道用品牌渐变；不用第四种语义色。
- **数字**：等宽；金额用 K/M/B；百分比一位小数；费率四位小数；时间用用户时区。
- **卡片右上角 "i"**：定义、来源、局限、更新时间，全站统一。
- **四态**：加载骨架、正常、降级（灰色 + 最后成功时间）、错误（重试）。不显示零来冒充数据。
- **分享**：首页光谱图、大户卡片、回放卡片、币页光谱可一键生成图片，带 hlens 水印与链接。这是免费获客的主要路径。
- **手机**：底部五键；页面第一屏放得下答案句 + 一张图；表格首列固定横向滚动；图表支持手势。
- **速度**：首屏 1 秒内可读（SSR），任何交互 100 毫秒内有反馈。
- **语言**：中英双语，术语表统一（如 crowding = 拥挤度，liquidation cluster = 爆仓堆）。

## 5. 优先级（按用户价值，不按开发难度）

| 优先 | 功能 | 为什么 |
|---|---|---|
| P1 | 币页答案句 + 光谱 + 我的仓位模式 | 让网站关于"我" |
| P1 | 价格标尺（危险在哪） | 每次设止损都要看 |
| P1 | 大户事件流 + 赌局板 + 快爆板 + 分享卡片 | 留人与传播 |
| P1 | 我睡觉时发生了什么 + 每日摘要推送 | 每天回访的理由 |
| P2 | 今天做哪个币（人话预设） | 开仓前的入口 |
| P2 | 告警（仓位套餐） | 持仓中的价值，付费点 |
| P2 | 回放 | 亏损后的价值，形成习惯 |
| P2 | 拿着多少钱 | 高频小需求 |
| P3 | 记分板与证据库 | 信任的来源，样本积累后才有意义 |
| P3 | 期权、基差、高级筛选表格 | 专业用户，少数 |
