- 09-19 **一台 VPS；后端 Python、数据库 PostgreSQL 已定不重开**；API 形态、前端框架、部署细节由 `03-ARCHITECTURE.md` 定。raphael 对框架熟不熟不是选型约束——代码由 agent 写；约束是 agent 在该语言上的返工率、生态是否对口、单人排障是否简单、月成本。
- 09-19 **蓝图不等于建造顺序**：功能清单全部保留，建造按里程碑推进，一次只开一个模块；按 15 小时/周排，不折算成日历日期。
- 09-19 **先架构、后开发**：功能定义 → 架构设计文档经 raphael 确认 → 才派编码任务。
- 09-19 **技术选型流程**：raphael 给产品需求 → `product-manager` 写功能定义与验收 → `architect` 在硬约束下选型（必须列出被否决的备选与理由，每个组件对应一条已确认需求）→ `reviewer` 挑错 → Claude 汇总并负责删减。两个角色的定义里都写明必须删减：只加不删的评审会堆出没人维护得了的方案。
