## 1. 一句话

**hlens CryptoPlus 是多所加密情报与量化研究系统：用棱镜把一个市场拆成价格、订单流、持仓、费率、流动性、参与者等多个面，面与面之间的分歧就是信息；只给状态、历史分布与可复现的研究结论，不给动作。**

第一切片：**Binance（CEX）+ Hyperliquid（DEX），永续合约**。一个 CEX 加一个 DEX 已足以显示口径分歧。

品牌语 "See more · Think deeper · Trade wiser" 只是标语，不是产品承诺；产品文案一律遵守 §4.1 的禁止词表。

## 2. 为什么做、凭什么赢

| 用户抱怨 | hlens |

| 单所视角，看不到分歧 | 同一指标在 CEX 与 DEX 两条独立链路上并排；口径差异写在页面上，不做无意义的加总 |

| 结论不可复现 | 研究与回测公开公式、公开样本量 n 与证据标签，规则版本化走 PR |
| 广告、登录墙、手机难用 | 无广告；核心不登录；手机优先 |

## 3. 用户

- **主：公开网站与社群。** 手机优先的永续交易者，中英双语；看状态、历史分位与一句人话答案，不登录即可用。
- **次：量化 / Agent 研究者。** 要证据、要能自己复核的人（API、MCP），也是将来的付费主体。
- **不服务**：要喊单、要目标价、要跟单的人。

## 4. 原则（不可协商）

1. **只描述，不建议。** 禁止词：建议、可以考虑、适合、机会、目标价、止损设在。允许：处于、转为、满足 X 条规则、历史分布数字。
2. **"策略"的边界**：在 hlens，策略 = **可复现的研究与回测**，结论必带样本量 n 与证据标签，公式与数据窗口公开、可重跑。**永远不是**交易信号、喊单、目标价或建议。标语里的 "Trade wiser" 指用户拿证据自己决策，不是本项目替谁决策。
3. **证据标签**（六种，全站统一）：`已验证` / `站内自验证`（预注册分组，n ≥ 100，FDR 校正后显著）/ `启发式` / `观点` / `样本不足` / `模型估算`。
4. **样本规则**：n < 10 的面置灰、不显示数值；n < 30 不显示百分比；任何统计都显示 n。
5. **新鲜度预算**（分面）：价格与费率 ≤ 60 秒、OI ≤ 2 分钟、多空比 ≤ 15 分钟、大户 ≤ 5 分钟（M5 起适用）、爆仓聚合 ≤ 5 分钟。超限的短语置灰并显示 `as_of`。
6. **公式公开、规则版本化**：阈值改动走 PR，附校准报告，进变更日志。
7. **不显示零冒充数据**；源故障时该源数字置灰并显示最后成功时间，不补零、不留空。**能力三问不合并**：`supported` / `mode` / `completeness` 分开声明；交易所限流的爆仓一律标 `lower_bound`。
8. **不碰用户资金**：无交易执行、无 key 托管、无收益分成。
9. **无广告；返佣明示且隔离**——返佣入口只出现在 `/sources`；美国与受制裁地区按 Cloudflare 国家头隐藏。
10. **钱包政策**（M5 起适用）：不做身份关联与跨链画像；措辞去情绪化；提供 opt-out 邮箱，7 日内脱敏。
11. **对外承诺尽力而为，无 SLA**；`/status` 公示 30 天真实可用率。

## 5. 范围与里程碑

### 5.1 读法

里程碑按依赖排序，每一个都交付看得见的东西，每一个都可以停在那里而产品仍然完整。小时数是**规模**，不是排期，不折算成日历日期（工时假设见 §7）。改起来贵的接缝在 `03-ARCHITECTURE.md §6` 一次定死，其余等做到时再定——在还没有代码的时候预留接口只会让文档变厚。

### 5.2 里程碑

| 里程碑 | 规模 | 交付 | 单条可判定验收 |
|---|---|---|---|
| **M1 两所跑起来** | ~160 h | 采集核心（归一化数据契约、按出口 IP 的限速预算、preflight 自检、带能力声明的适配器协议、Binance 与 Hyperliquid 行情适配器）；分钟级采集器进程；PostgreSQL 表结构；每日备份；采集静默 > 10 分钟的心跳告警（Telegram 私聊 + 邮件）；只读运行状态后台（仅 raphael 可见） | 连续 14 天两源分钟级采集绿色 ≥ 95%，磁盘增长在容量估算 ±20% 内，并完成一次恢复演练 |
| **M2 站点首版** | ~130 h | 跨所分歧榜；30 天历史分位；**公开站首版**（一币一卡、两所并排、纯 HTML/CSS/JS，无构建步骤、无框架，只读采集器导出的版本化 JSON）；每日 Telegram 摘要；首篇可复现研究；爆仓事件流（`lower_bound`） | 5 人任务测试（3 个任务，60 秒内答对）≥ 4/5 |
| **M3 产品化** | ~180 h | 精简 REST API；我的仓位（纯本地）；Telegram 告警；我睡觉时；一句话答案（句子引擎）；监控 | 契约测试全绿（实现与对外契约一致），且告警链路端到端真实触发一次 |
| **M4 重数据** | ~150 h | 逐笔成交 → CVD；盘口深度；现货。**整块门控于容量实测**，不达标就不开 | 白名单币开启后连续 7 天，磁盘增长与限速预算占用均在容量表内 |
| **M5 大户** | ≥ 200 h | 钱包协议 + Hyperliquid 钱包方法；hub 历史导入；大户引擎；五块板；钱包页；分享卡。**导入与大户功能同进同退，不允许只做一半** | 五块板上每个数字都能由导入数据用同一脚本重算出同值，且展示窗口晚于 hub 采集的 P95 延迟 |
| **M6 可信层** | ~190 h | 状态词典 + 校准报告；记分板；关键价位 / 爆仓热力图模型（必带 `模型估算`）；`/method` `/status` `/changelog` `/evidence` | 校准四项验收全过并出报告文件；同一研究脚本重跑得到同一结论与同一 n |

两条口径说明：

1. **M6 卡的是时间，不是工作量。** 状态词典与记分板需要 M1 之后**至少 3 个月**的自采历史，时钟从采集上线那天开始走——这就是 M1 要尽早开始的全部理由，没采的分钟永远补不回来。
2. **Hyperliquid 不发布多空比端点**，自算需要钱包级仓位数据，因此 M5 之前该面对 Hyperliquid 显示"该所不发布"，不留空、不补零。

### 5.3 以后（未排期，未取消）

## 6. 数据资产：hub 的 Hyperliquid 历史数据集（M5 起使用）

raphael 的 hub 机器（Tailscale `100.79.90.118`）持续采集 Hyperliquid，Parquet 分区在 `/mnt/data1/hlens-hub/data/curated/hl/`。这是无法被别人复制的资产，也是 M5 五块板"上线第一天就有 n ≥ 100"的前提。

| 表 | 规模 | 时间范围 | 用途 |
|---|---|---|---|
| fill_history | 11 GB | 2023-02-28 → 2026-08-03 | 大户事件历史、记分板、钱包命中率 |
| fill | 5.29 亿行 | 2026-07-11 → 今 | 与上表拼接为连续序列 |
| position | 2270 万快照 | 2026-08-01 → 今 | 事件对账、强平价历史 |
| liquidation | 57 万行（去重 53.8 万笔） | 成交时间 2024-03-16 → 今（`dt=` 为观测日，实时采集自 2026-09-08） | Hyperliquid 强平，见下方限制 |
| leaderboard | 4550 万行 | 2026-08-01 → 今 | 候选池种子、账户价值历史 |
| account_snapshot | 3530 万行 | 2026-08-01 → 今 | 权益曲线 |
| funding / kline | 34 万 / 125 万行 | 多所 | 回填事件后收益 |

**liquidation 的实测限制**：它是从在册钱包的 fills 派生的样本，是 `lower_bound` 而非全量。实时窗口完整度按金额约 95%、按币 51–93%，采集延迟中位约 6 小时；历史段捕获率仅 1.6–8%，**不可跨期画趋势**。全所级真值只能走节点数据（列入 §5.3）。测量方法与逐项数字见 `04-DATA-SOURCES.md`。

两条决定：**导入代替回填**（数据已经在，重新采一遍是浪费）；**hub 只做研究与导入源，不进生产链路**。仍然拿不到的是中心化交易所的 OI 与爆仓历史，因此 M6 的状态词典首版只用价格类特征校准。

## 7. 硬约束

| 约束 | 数字 | 含义 |
|---|---|---|
| 维护人力 | 一个人 | raphael 是产品负责人，代码由 agent 写；任何方案的排障成本必须由一个人扛得住 |

## 8. 社群

首发只做 Telegram 频道（广播），满 300 人再开群；X 只发自动分享卡；不做微信群。自动内容：每日摘要（今天最不正常的 3 个币）。人工内容：每周一篇复盘，亏损优先。冷启动：发布前三周在 r/Hyperliquid、r/algotrading 做回答式参与，再发三篇文章。归因：站内 TG 入口用 `t.me/<bot>?start=src_<page>` 深链。群规则：不喊单、不发合约链接、不承诺收益。大户相关的自动内容（分享卡、级联卡）从 M5 起才有。

## 9. 商业化

展示层**永久免费**，这是分享与 SEO 的前提。Pro 卖**额度**而不是卖结论：API / MCP 配额、告警条数、历史深度、导出，19–29 美元/月，面向开发者与量化研究者——整块列在 §5.3，等待名单 ≥ 50 个邮箱才接支付。返佣只做 Hyperliquid 邀请码，按 §4.9 隔离在 `/sources`，美国与受制裁地区不显示。永不做：收益分成、代客交易、付费信号。

## 10. 风险

| 风险 | 对策 |
|---|---|
| 交易所接口变更、封锁、ToS 限制再分发 | 适配层隔离，加一个所 = 加一个文件；每源熔断；`/sources` 写清每所条款结论；生产走非美出口与规范域名 |
| 爆仓数据系统性偏低（交易所限流） | 一律标 `lower_bound`；不做总量、不跨所比总额；总量只写"点名交易所 + ≥"；级联判定用相对阈值 |
| 只有两所，被说"覆盖不够" | 明说这是纵向做透的选择；一个 CEX + 一个 DEX 已能显示口径分歧；更多交易所在 §5.3 |
| 后期数据量炸掉单台 VPS | 容量表先行；逐笔与盘口按币白名单开启；不达标就不开（M4 的门控） |
| 研究与记分板假阳性 | 预注册分组、BH-FDR 校正、块 bootstrap、Wilson 区间；结论必带 n 与证据标签；"没有发现效应"照样发布 |
| 免费层 VPS 被回收或宕机 | 每日异地备份 + 重建脚本 + 应急预算；降级模式走静态托管；每月恢复演练 |
| 单人维护 | 运行手册、心跳与死人开关、只读运行状态页、每月演练 |
| 法律 | 四页法律与来源页随站首版上线（M2，见 `02-FEATURES.md` F9）；只描述不建议；钱包政策；GDPR 导出与删除 |
| 头像使用 Binance / Hyperliquid 官方 logo | 可能暗示关联，而 `/disclaimer` 声明无关联。选项：去掉 logo / 改文字 / 各处简介加 "not affiliated"。**待 raphael 定，不阻塞开发** |
| 范围本身约 1100 小时 | 每个里程碑都交付看得见的东西，按 15 小时/周排；蓝图不是排期，任何一个里程碑都可以是终点 |
