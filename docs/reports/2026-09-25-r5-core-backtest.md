# R5 V9-core 回测（开发集，2026-09-25）

> 命令：`uv run python scripts/run_backtest.py`。配置 `9.0-core.1`。区间：信号 2020-09-01 → 2023-12-31，不含留出集。
> 核心（D6）：4H 门控 + 1H 趋势方向 + 1H 回调中的 15m 顺势 BOS + 结构止损；单笔风险 0.5%；止损随新确认的 1H 摆动点移动；D2 收回窗口 3 根 1H；同一逻辑最多 3 次入场。
> 成本全开：手续费每边 0.05%、滑点每边 0.02%、实际资金费率。引擎测试含整条流水线的无前视检验（截断前已平仓的交易必须完全一致）。

## 2. 诊断

1. **形状对了，幅度不够**：正偏态、低胜率、少数交易贡献绝大部分利润——这正是框架 §0 想要的收益分布；但胜率 22% 低于盈亏平衡所需的 24.7%，净期望为负。
2. **盈利被移动止损截短**：盈利单平均最大浮盈 5.37R，只兑现 2.83R（53%）；106 笔亏损单里 34 笔曾经浮盈 ≥ 1R。止损跟随每一个新确认的 1H DC 摆动点（阈值 2 × ATR），对框架「+2R → +3R → +5R → +8R 持有」来说太紧。
3. **多空严重不对称**：做多 78 笔、均值 +0.18R、合计 +14.2R；做空 58 笔、均值 -0.49R、合计 -28.3R。做空在 2022 熊市也亏（18 笔，-9.9R）。做多的盈利几乎全部来自 2020 年四季度（+10.6R），其余年份接近 0。
4. **4H 状态之间无差别**：TREND 98 笔、均值 -0.07R；PULLBACK 38 笔、均值 -0.18R。
5. **D2 平仓从未触发**：移动止损（摆动点下方 0.25 ATR）总是先于「3 根 1H 未收回」被打到。D2 在当前参数下不起作用。
6. **重新入场很少**：130 笔首次入场、6 笔第二次入场（均值 -0.96R）；第三次从未发生。
7. 交易数 136 少于漏斗报告估计的约 197：同一时间只持一个仓位、名义价值上限与止损距离过滤会挡掉一部分信号。

## 3. 与基线比较

最好的基线 B1 MA50 只做多：夏普 1.14、最大回撤 -60.9%。V9-core：夏普 -0.34、最大回撤 -19.5%。回撤小，是因为 0.5% 固定风险的仓位小，不是因为有优势。**不满足计划 §3 的门槛**（夏普 > 1.14，或夏普 ≥ 0.9 且回撤更小）。
