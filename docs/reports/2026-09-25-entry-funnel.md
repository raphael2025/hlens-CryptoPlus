## 3. 结论

1. **计划原样过严**：开发集只有 34 笔，远低于计划自己要求的 n ≥ 100，任何结论都只能标「样本不足」；2022 年全年只有 4 笔。
2. **最大的卡点是 Q / 深度过滤**（143 → 34，砍掉 76%）；趋势阶段过滤几乎不影响次数。而「强主动段 + 弱回调 → 延续」在证据调研里是 **弱 / 无**。
3. 条件是乘法叠加的：每加一层没有证据的过滤，都在同时减少样本、增加可调参数，过拟合风险随之上升。
4. **处理**：研究计划改为「最简核心 + 逐条加条件」——核心只保留 4H 门控、1H 趋势方向、15m BOS、结构止损（对应 V6，约 60 笔 / 年，开发集约 200 笔）；趋势阶段与 Q / 深度改为预注册假设 H9、H10，和机制层一样只能在证明有增量后加入。见 `docs/02-RESEARCH-PLAN.md` D6。
