> 命令：`uv run python scripts/run_entry_study.py`。配置 `9.1-trader.1`，规则与判定标准见计划 §7（先于结果提交，commit 19675d6）。
> 只看入场，不看出场：入场 = 信号下一根 15m 开盘；自然止损 = 猎杀低点 − 0.25 × ATR(1H)，自然 R = 入场到止损的距离。以下为成本前数字，往返成本约 0.13R（按中位止损距离）。

| 项 | 值 |

| 4H 可交易时间 | 52.9% |
| 4H 可交易且 1H 维加斯回踩成立 | 7.9% |

4H 回踩条件几乎不过滤（81 → 76）：价格回到 1H 通道并扫损时，4H 基本都在回踩 EMA21。**n < 100，按计划所有结论标「样本不足」。**

## 2. 入场之后 72 小时发生了什么

| 组 | n | 先到 +2R | 先到 +3R | 最大有利中位 | 最大不利中位 | 24h 方向收益 |
|---|---|---|---|---|---|---|
| E-no4hpb 信号 | 81 | 37.0% [27.3, 47.9] | 28.4% [19.7, 39.0] | **3.08R** | 1.97R | +0.12 ATR |
| E-full 信号 | 76 | 36.8% | 27.6% | 3.12R | 2.22R | +0.13 ATR |
| 随机：同 4H 状态 | 20000 | 33.4% | 24.0% | 2.38R | 2.20R | +0.15 ATR |
| 随机：1H 回踩成立、无猎杀 | 20000 | 33.9% | 23.9% | 2.38R | 2.06R | +0.10 ATR |

信号减随机（先到 +2R）：+3.2 至 +3.7 个百分点，95% 区间约 [-7%, +14%]；先到 +3R：+3.6 至 +4.5 个百分点，区间约 [-6%, +14%]。

## 3. 结论

1. **入场优势方向为正，但没有被证实**：信号在「先到 +2R / +3R」上比随机高 3–4 个百分点，最大有利波动明显更大（中位 3.1R vs 2.4R），但 81 个样本的区间都包含 0。按计划的判定标准，**T1 未通过，结论为样本不足**，不是「入场无效」。
2. **你的感觉被数据量化了**——入场后价格常常走对，但止损也常常被打：
   - 72 小时内 **50.6%** 的信号浮盈到过 +3R；
   - **70.4%** 的信号碰到过猎杀低点下方的止损；
   - **33.3%** 两者都发生过。
   也就是说，把止损放在猎杀低点下方太近：之后常有第二次扫损。这正是 T2 要解决的问题。
3. 作为参考（**非预注册，只作探索**）：固定 3R 止盈 / 1R 止损、最多持有 72 小时，成本后约 +0.25R / 笔；2R / 1R 约 +0.04R / 笔。样本太小，不能当证据。
4. 方向与年份：做空 38 笔、先到 +2R 47%；做多 43 笔、28%；2023 年最差（24h 方向收益 -0.73 ATR）。样本太小，不解读。
