# R2 基线 B0 / B1（开发集，2026-09-25）

> 命令：`uv run python scripts/run_baselines.py`。区间：2020-09-01 → 2023-12-31（1217 天），不含留出集。
> 成本全开：吃单手续费 0.05% + 滑点 0.02%（每次调仓按换手计），按实际资金费率计费（多头付正费率）。
> B1：日收盘价 / N 日均线 > 1 做多，否则空仓（long-only）或做空（long-short）；仓位 = 50% 年化目标波动 ÷ 20 日实现波动，上限 2 倍。参数在任何结果出来之前写入 `config/v9.yaml`。

## 2. 解读

1. **趋势跟随在开发集上有正收益，但很不稳**：6 个 B1 里 5 个夏普为正；MA50 最好（1.14），MA20 多空接近 0。三个窗口差别这么大，说明「选哪个 N」本身就是过拟合来源——这正是计划要求全部报告、不挑选的原因。
2. **2022 年所有只做多版本都亏**，多空版本里只有 MA100 在 2022 年为正。与文献一致：趋势跟随在 2022 熊市与震荡期表现差。
3. 回撤普遍在 45%–80%：这是 BTC 日线趋势的真实代价，V9 的每笔 0.5% 固定风险应当显著降低回撤，这是它相对 B1 最可能的优势。
4. 这 7 个基线的日收益已存到 `data/results/baseline_daily_returns.json`，供 R5 计算 V9 的 Deflated Sharpe 时作为「试验次数」的参照。

## 3. V9 要跨过的线（计划 §3）

V9-core 在开发集上扣成本后，要么**夏普 > 1.14**（最好的 B1），要么在**夏普接近（≥ 0.9）的前提下最大回撤明显更小**（< 45%，即好于最好的 B1 回撤）。两条都达不到，复杂度就没有意义。

## 4. 统计模块

`src/v9/stats.py`：bootstrap 期望值区间、Wilson 区间、t 值、偏度 / 峰度、最长连亏、蒙特卡洛连亏与 R 回撤、夏普、PSR、DSR。测试确认蒙特卡洛连亏复现了此前报告的数字（胜率 30%、100 笔：P50 = 10，P95 = 17）。
