## 1. 一句话

**hlens 是合约交易者的棱镜：把一个币的永续市场拆成散户、大账户、链上大户、费率、持仓、爆仓、期权七个面，回答交易者在六个时刻的六个问题，只给状态不给动作。**

## 2. 为什么做、凭什么赢

| 现状 | hlens |
|---|---|
| 数据站是图表堆，用户要自己找 | 按问题组织：每页第一行是一句人话答案，图表是证据 |
| 数据与用户无关 | "我的仓位"模式：本地输入仓位，全站数据相对于你 |
| 解读靠喊单，无法验证 | 只给状态；每句解释带证据标签；命中率公开滚动 |
| 广告、登录墙、手机难用 | 无广告；核心不登录；手机优先 |
| 大户只是一张表 | 大户是故事：赌局、快爆、认输、赢家输家，一键分享 |

## 3. 用户

- 主：全球中英文永续合约散户，账户 500 到 5 万美元，每天看盘 1 到 3 次，手机为主。
- 次：小型量化 / 自营 / 内容创作者，用 API 与 MCP。
- 明确不服务：想要喊单的人、想跟单的人。

## 4. 原则（不可协商）

1. **只描述，不建议。** 禁止词：建议、可以考虑、适合、机会、目标价、止损设在。
2. **每句解释带标签**：`已验证`（外部数据、方法、效应量可查）/ `站内自验证`（记分板 n ≥ 100 且置信区间不含零）/ `启发式` / `观点`。
3. **公式公开、规则版本化**：任何阈值改动走 PR，附校准报告，进变更日志。
4. **不显示零冒充数据**：源故障显示灰色与最后成功时间。
5. **不碰用户资金**：无交易执行、无 API key 托管、无收益分成。
6. **无广告；返佣明示。**

## 5. 范围

做：M1 棱镜 · M2 筛选（人话预设）· M3 费率 · M4 持仓与多空 · M5 爆仓（真实流 + 标尺 + 模型热力图）· M6 大户（事件、三板、记分板、钱包页）· M7 市场环境（状态词典、关键价位、24h、动力来源、风险换算、日历）· M8 我睡觉时 · M9 回放 · M10 我的仓位 · M11 告警 · M12 API/MCP · M13 方法与记分板 · M14 期权基差（低优先）· M15 管理后台。
不做：现货交易所深度分析、链上转账追踪、NFT、社交排行、跟单执行。

## 6. 六个不满意的改进决定

| # | 问题 | 改进（细节在 01-FEATURES 对应节） |
|---|---|---|
| 1 | 一句话答案未验证 | 建立**句子引擎**：模板语法、优先级、矛盾消解、置信门槛、双语模板；50 个历史快照的黄金测试集；每周人工审核 100 句；所有生成句写入 `sentence_log` 可审计。上线前用 30 天历史回放生成句子并人工评分 ≥ 4/5 才放行。 |
| 2 | 状态阈值是拍的 | 建立**校准流程**：用 2 年 1h 数据、前 50 币跑状态规则，输出频率表、转移矩阵、持续时长、后续收益分布；验收：每个状态频率 2%–35%、中位持续 ≥ 3 根、无状态占比 > 40%、相邻状态抖动率 < 15%；阈值存 `config/state_rules.v1.yaml`，改动附报告。 |
| 3 | 大户样本小、只有 HL | 候选池扩到 HL 前 1000 + 大额成交发现（HL trades 流中 ≥ 100 万美元的地址）+ **OKX 带单交易员公开榜**（公开接口，含当前仓位）作为中心化交易所大户样本；记分板按样本量分级显示，n < 30 只显示"样本不足"；预计 90 天达到 n ≥ 100 的分组。 |
| 4 | 视觉无设计 | 定义**视觉识别**：棱镜图几何与编码规范、设计令牌、分享卡三种模板、动效规则；P1 前先出设计稿（design canvas）评审，再写前端。 |
| 5 | 文档重叠 | 合并为本套四份；旧版归档只读。 |
| 6 | 社群无运营 | 第 9 节运营方案：内容由数据自动生成为主，人工复盘每周一篇，角色与规则明确。 |

## 9. 社群运营方案

- **平台**：Telegram 频道（广播）+ 群（讨论）为全球主入口；X 账号发分享卡；微信群作中文补充（二维码在站内）。
- **自动内容（由站点生成，零人力）**：每日 00:00 UTC 摘要（一张全市场光谱图 + 五条要点）；大户事件 ≥ 2000 万美元即时卡片；级联事件卡片；每周状态统计卡（哪个状态出现最多、记分板变化）。
- **人工内容（每周一篇）**：复盘一次真实交易或一次市场事件，用回放页截图，写清当时状态、之后发生什么、什么判断错了。亏损优先写。
- **群规则**：不喊单、不发合约链接、不讨论收益承诺；违规一次警告两次移除。
- **角色**：raphael 作者与最终裁决；Claude 生成自动内容与草拟复盘；志愿管理员 2 名（来自早期成员）。
- **漏斗与指标**：站→频道点击率 ≥ 3%；频道→群转化 ≥ 20%；群周活 ≥ 30%；分享卡外链回流占新访客 ≥ 15%。
- **冷启动**：发布前两周先在 X 与 Reddit r/CryptoCurrency、r/Hyperliquid 发三篇有数据的文章（散户 vs 大户分歧、健康回调 vs 危险回调、大户开仓后价格怎么走），文末给站点链接，不做广告投放。

## 10. 风险

| 风险 | 对策 |
|---|---|
| 交易所接口变更或封锁 | 每源熔断与降级；两机异地；诊断工作流；接口适配层隔离 |
| 状态与句子被市场打脸 | 记分板公开；措辞规范；标签制度；不做预测 |
| 法律 | 免责声明、只描述不建议、无资金接触、返佣明示、GDPR 导出删除 |
| 单人维护 | 文档齐全、运行手册、告警到手机、每月恢复演练 |
| 无人来 | 分享卡与自动内容是免费获客主路径；发布前三篇文章；不投广告 |
