## 1. 一句话

**hlens 是合约交易者的棱镜：把一个币的永续市场拆成散户、大账户、链上大户、费率、持仓、爆仓六个面，回答交易者在六个时刻的六个问题，只给状态与历史分布，不给动作。**

## 2. 为什么做、凭什么赢

| 用户抱怨 | hlens |
|---|---|
| 图表堆，要自己找 | 每页第一行一句人话答案，且每个数字带历史分位（"比过去 30 天 91% 的时候都挤"） |
| 数据与我无关 | "我的仓位"：本地输入，换三件具体的事：距爆仓堆多远、每天付多少费率、换所省多少 |
| 解读靠喊单 | 只给状态与该状态的历史后果分布；样本不足就明说"样本不足"，不给百分比 |
| 大户只是表 | 大户是可验证的故事（五块板：赌局、快爆、已平仓亏损、赢家、输家），每条可点链上核对，一键分享 |
| 广告、登录墙、手机难用 | 无广告；核心不登录；手机优先 |

## 3. 用户
主：全球中英文永续散户，手机为主。次：量化 / Agent 开发者（API、MCP，付费主体）。不服务：要喊单、要跟单的人。

## 4. 原则（不可协商）
1. **只描述，不建议。** 禁止词：建议、可以考虑、适合、机会、目标价、止损设在。允许：处于、转为、满足 X 条规则、历史分布数字。
2. **证据标签**：`已验证` / `站内自验证`（预注册分组，n ≥ 100，FDR 校正后显著）/ `启发式` / `观点` / `样本不足` / `模型估算`。
3. **样本规则**：n < 10 的面置灰不显示数值；n < 30 不显示百分比；任何统计显示 n。
4. **新鲜度预算**（分面）：价格与费率 ≤ 60 秒、OI ≤ 2 分钟、多空比 ≤ 15 分钟、大户 ≤ 5 分钟、爆仓聚合 ≤ 5 分钟；超限的短语置灰并显示 `as_of`。
5. **公式公开、规则版本化**：阈值改动走 PR，附校准报告，进变更日志。
6. **不显示零冒充数据**；源故障显示灰色与最后成功时间。
7. **不碰用户资金**；无交易执行、无 key 托管、无收益分成。
8. **无广告；返佣明示**，返佣入口只出现在 `/sources` 与 `/me`，不出现在记分板、钱包页、币页；美国与受制裁地区按 Cloudflare 国家头隐藏。
9. **钱包政策**：不做身份关联与跨链画像；措辞去情绪化（"已平仓，实现亏损 X"而非"认输"）；提供 opt-out 邮箱，7 日内脱敏。
10. **对外承诺尽力而为，无 SLA**；`/status` 公示 30 天真实可用率。

## 5. 范围（v1.0）
做：棱镜 · 人话预设筛选 · 费率 · 持仓与多空 · 爆仓（真实流 + 价格标尺 + 模型热力图对照）· 大户（事件、五板、记分板、钱包页）· 市场环境（状态词典、关键价位、24h、现货 vs 永续、OI 象限）· 我睡觉时 · "当时看"回放 · 我的仓位 · 告警（Telegram）· API/MCP · 方法与记分板 · 法律与状态页。
砍：管理后台（用 psql + Grafana）· 微信群 · 市场环境的 CVD 与盘口厚度面板 · 高级筛选表格。
后移 v1.1：告警 Webhook、期权与基差（含期权隐含波动）、OKX 带单源、Pro/Stripe（等待名单 ≥ 50 才启动）、Gate/Bitget 第五第六所。回放保留为深链页 `/replay?symbol=&at=`（从"当时看"进入），属 v1。

## 7. 基础设施
| 机器 | 角色 |
|---|---|
| 东京 | **主库**（数据产生地）：Postgres/Timescale、Redis、采集器（REST + WS）、大户引擎、分析、告警引擎 |
| 新加坡 | 只读副本、API、Web、待命 API、第二个 cloudflared 连接器、Prometheus/Grafana |
| hub（笔记本） | `hlens-hub` 生产采集与 GitHub `hlens` 档案系统继续以 systemd 运行，**不容器化、不进 CryptoPlus 的 compose**；作为历史数据导入源（只读）与离线校准机 |
| 法兰克福 / 上海 | 不用 |
| GitHub Pages | **降级模式**：API 每 30 分钟推 `latest.json`；主站不可用时 Worker 回退到只读快照 |

约束：东京的公网出口 IP 必须与 hub 任一 worker 不同（交易所限速按出口 IP 记账）；hub 上两处安全问题（`hub.env` 明文 secret、admin 端点无鉴权绑 0.0.0.0）由 raphael 在 S0 处理。Docker 落地见 `05-DOCKER.md`，代码复用见 `04-ARCHITECTURE-REVIEW.md`。
Cloudflare 免费层（DNS、Tunnel 双连接器、缓存规则、WAF、Web Analytics）；R2 备份约 1.5 美元/月；Sentry、Better Stack（心跳与死人开关）、Resend 免费层。**前置任务**：核实两台免费 VPS 的规格与回收政策，写入容量表；免费 VPS 失效应急预算 40 美元/月，数据与配置全部在 R2 可 2 小时重建。
承诺：RPO ≤ 5 分钟（WAL 归档）、RTO 1 小时（人工提升）；无 SLA。

## 9. 社群运营
- 首发只做 Telegram 频道（广播）；频道 ≥ 300 人再开群；X 只发自动分享卡；不做微信群。
- 自动内容：每日摘要（今天最不正常的 3 个币 + 大户三条）、大户事件 ≥ 2000 万美元即时 WhaleCard、级联卡。
- 人工内容：每周一篇复盘（用"当时看"截图，亏损优先）。
- 冷启动：发布前三周在 r/Hyperliquid、r/algotrading 做回答式参与，再发三篇文章。
- 归因：所有 TG 入口用 `t.me/<bot>?start=src_<page>` 深链；站内事件表记录 `event, path, ref, ts`。首月只观测不设目标。
- 群规则：不喊单、不发合约链接、不承诺收益。
