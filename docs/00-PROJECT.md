## 1. 一句话

**hlens CryptoPlus 是多所加密情报与量化研究系统：用棱镜把一个市场拆成价格、订单流、持仓、费率、流动性、参与者等多个面，各面之间的分歧就是信息；只给状态、历史分布与可复现的研究结论，不给动作。**

第一切片：Binance（CEX）+ Hyperliquid（DEX），永续合约。品牌语 "See more · Think deeper · Trade wiser" 只是标语，产品文案一律遵守 §4.1 禁止词表。

## 3. 用户

主：自主决策的永续交易者与量化 / Agent 研究者——要证据、要能自己复核的人（API、MCP，付费主体）。次：全球中英文散户，手机为主，看状态与分位。**不服务**：要喊单、要目标价、要跟单的人。

## 4. 原则（不可协商）

1. **只描述，不建议。** 禁止词：建议、可以考虑、适合、机会、目标价、止损设在。允许：处于、转为、满足 X 条规则、历史分布数字。
2. **"策略"的边界**：在 hlens，策略 = **可复现的研究与回测**，结论必须带样本量 n 与证据标签，公式与数据窗口公开、可重跑。**永远不是**交易信号、喊单、目标价或建议。标语里的 "Trade wiser" 指用户拿证据自己决策，不构成本项目给出决策。
3. **证据标签**：`已验证` / `站内自验证`（预注册分组，n ≥ 100，FDR 校正后显著）/ `启发式` / `观点` / `样本不足` / `模型估算`。
4. **样本规则**：n < 10 的面置灰不显示数值；n < 30 不显示百分比；任何统计显示 n。
5. **新鲜度预算**（分面）：价格与费率 ≤ 60 秒、OI ≤ 2 分钟、多空比 ≤ 15 分钟、大户 ≤ 5 分钟（范围待定，见 §5.4）、爆仓聚合 ≤ 5 分钟；超限的短语置灰并显示 `as_of`。
6. **公式公开、规则版本化**：阈值改动走 PR，附校准报告，进变更日志。
7. **不显示零冒充数据**；源故障显示灰色与最后成功时间。**能力三问不合并**：`supported` / `mode` / `completeness` 分开声明；交易所限流的爆仓流一律 `lower_bound`。
8. **不碰用户资金**；无交易执行、无 key 托管、无收益分成。
9. **无广告；返佣明示**，返佣入口只出现在 `/sources` 与 `/me`；美国与受制裁地区按 Cloudflare 国家头隐藏。
10. **钱包政策**（范围待定，见 §5）：不做身份关联与跨链画像；措辞去情绪化；提供 opt-out 邮箱，7 日内脱敏。
11. **对外承诺尽力而为，无 SLA**；`/status` 公示 30 天真实可用率。

## 5. 范围

### 5.1 Phase 1（现在做）：Binance + Hyperliquid 永续

价格 / 标记价 · 资金费率 · 持仓量（OI）· 多空比与主动买卖比（**仅在该所公开发布时**：Binance 有；HL 无官方多空比端点，自算需要钱包级仓位数据，门控于 §5.4，Phase 1 该面对 HL 显示"该所不发布"而非留空或补零）· 爆仓（`lower_bound` 事件流，不做总量、不跨所比总额）· K 线 · 合约元数据（`instruments`）· 币页与首页 · 中英 · 法律与状态页 · 研究与回测的最小可复现链路。

### 5.2 Phase 2（恢复但后移）：订单流、流动性、现货

逐笔成交 → CVD · 盘口深度 · 现货。**这两项在 v3.1 §5 被明确砍掉**（"市场环境的 CVD 与盘口厚度面板"），v4 恢复为正式目标但排在 Phase 1 之后。理由与代价：它们是数据量与限速最重的一类（逐笔与盘口的消息量比行情面高一到两个数量级），必须在 Phase 1 的采集与存储跑稳、容量表可信之后才开工。

### 5.3 Phase 3（积压，无排期）：更多交易所、多资产

Bybit、OKX、Gate、Bitget（未审查的半成品停在远端分支 `S0-4a`（`73d89f5`：`bybit.py`、`okx.py` + fixtures，**无测试**）与 `S0-4b`（`498f174`：`gate.py` + Gate/Bitget fixtures，**Bitget 适配器本体未写**，无测试），**均未合并**）· 多资产扩展。

### 5.4 待定（raphael 未决，不排工）

**钱包 / 大户追踪（头像上的 Trader Behavior / On-Chain）属于本项目，还是留在另一个项目、CryptoPlus 只消费其产出？** 依赖该决定的东西：HL 适配器的钱包方法 · 大户引擎与五块板 · 钱包页与 WhaleCard · hub 历史导入（原 S0-6）· OpenAPI 的 `whales` 组端点 · 线上静态站的鲸鱼透镜。**决定之前**：HL 适配器只实现行情方法；§6 的 hub 数据集仍作为已记录的资产保留，但其使用被该决定门控。

### 5.5 v3.1 已规划、v4 未排期（未取消，待 raphael 复核）

我的仓位（纯本地：距爆仓堆多远、每天付多少费率、换所省多少）· Telegram 告警 · 我睡觉时 · "当时看"回放（`/replay`）· 人话预设筛选 · 关键价位与价格标尺 · 模型热力图对照。规格仍在 `01-FEATURES.md`；它们没有进入 R0–R3，也没有被砍，R2 开工前逐项定去留。

### 5.6 不做 / 不动

管理后台（用 psql + Grafana）· 微信群 · 高级筛选表格 · 期权与基差（后移）。**线上静态站不动**：GitHub Pages + `scripts/fetch.py` 每 30 分钟、六所、鲸鱼透镜、法律页照常运行，不属于本次重启范围（改动规则见 `AGENTS.md` §2 第 1 条）。
