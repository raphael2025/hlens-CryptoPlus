# hlens · 用户视角的功能与显示定义（v2，与 PRODUCTION-SPEC 并列，页面以本文为准）

> 写法：先说用户在什么时刻带着什么问题打开网站，再定义那一页显示什么、第一句话说什么、图表证明什么、手机上怎么看。技术实现见 `PRODUCTION-SPEC.md`。
> 原则：每一页回答一个问题；第一屏第一行是人话答案；图表只用来证明那句话；一切数据可切换到"相对于我的仓位"；不放广告；手机优先。

---

## 0. 我们凭什么被访问

| 用户的抱怨（对 Coinglass 类站点） | hlens 的回答 |
|---|---|
| "一堆图，我不知道该看哪张" | 六个问题六个页面，第一行就是答案，证据在下面 |
| "这些数据和我的仓位没关系" | **我的仓位模式**：本地输入仓位，全站数据变成相对于你的 |
| "看完了，然后呢？" | 每个数字后面跟一句"所以"，并标注是已验证、启发式还是观点 |
| "广告、弹窗、登录墙" | 无广告；核心功能不登录；登录只为告警和保存 |
| "手机上根本没法用" | 手机优先设计，底部五键，单手可用 |
| "看不出谁在骗我" | 公开记分板：我们自己的信号命中率公开滚动，错了也显示 |
| "大户数据只是一张表" | 大户是故事：谁在赌什么、谁快爆了、谁刚认输，可一键分享成卡片 |

## 2. "我的仓位"模式（贯穿全站）

- 入口：顶栏"＋ 我的仓位"。表单四项：币、方向、开仓价、杠杆（可选：金额、止损）。存在浏览器本地，不需要注册；登录后可同步。最多 10 个仓位。
- 开启后全站变化：
  - 每页顶部出现仓位条：币 · 方向 · 开仓价 · 当前盈亏 % · 距强平 % · 今日费率成本 · 一句风险评价（如"人群和你同向且拥挤，费率对你不利"）。
  - 棱镜页：光谱条上标出"你"的位置；"分歧陈述"改为"和你的关系"（大户与你同向 / 反向）。
  - 价格标尺：画出你的开仓价、止损、强平价，与爆仓堆和大户强平价的距离用数字标出。
  - 费率页：直接算你每 8 小时、每天、持有到目标日的成本。
  - 大户页：筛选"和我反向的大户"。
  - 告警：一键创建"我的仓位"套餐：距强平 < 10%、费率对我不利超过阈值、大户反向大额开仓、级联开始、人群反向拥挤度突破。
- 免责：仓位数据只在本地；我们不知道你的账户；这不是交易建议。

## 3. 逐页定义

### 3.1 首页 `/`：现在怎么样？

第一屏（手机一屏放得下）：
1. **一句话市况**（自动生成，带证据标签）：例如"BTC 多头拥挤 +0.31，散户 59% 做多，追踪大户 34% 做多；过去 1 小时爆仓 1200 万美元，多头占 80%。"
2. **六张问题卡**（两列三行）：
   - 我来晚了吗？→ 最拥挤的三个币，各一条拥挤度小条
   - 危险在哪？→ BTC/ETH 距离最近爆仓堆的百分比
   - 大户在干什么？→ 最近三条大户事件
   - 我睡觉时？→ 过去 8 小时三件大事
   - 拿着多少钱？→ 费率最贵和最便宜的三个币
   - 谁快爆了？→ 距强平最近的三个大户仓位
3. **我的仓位摘要**（若已设置）：每个仓位一行。
4. **全市场光谱图**（标志性视觉）：前 30 币各一条竖向光谱，颜色 = 拥挤度，高度 = OI，点击进币页；可"保存为图片"分享。
5. 更新时间与数据源红绿灯。

### 3.2 我睡觉时发生了什么 `/missed`

- 时间范围切换：8h / 24h / 自定义（默认按用户时区的"昨晚 23:00 到现在"）。
- **时间线**（纵向，按时间）：只放五类事件，每类一个图标：
  - 价格：±3% 以上的 15 分钟波动（币、幅度、时间）
  - 爆仓：单币 5 分钟内 ≥ 1000 万美元，或级联事件
  - 费率：8h 口径超过 ±0.05%，或跨所价差 > 0.03%
  - 大户：≥ 500 万美元的开/平/翻转，或大户被强平
  - 人群：拥挤度穿越 ±0.3
- 每条事件：一行标题 + 一行数字 + "当时看"按钮（跳回放）。
- 顶部三句话总结（自动）："BTC 夜间下探 2.4% 后回升；多头爆仓 3800 万美元；两个大户在 76,500 附近加多。"
- 可订阅为每日摘要推送（免费）。

### 3.3 币页：我是不是来晚了 `/coin/[symbol]`

第一屏：
1. **答案句**：三种之一，附拥挤度数值与证据标签：
   - "人群已经很挤了：多头拥挤 +0.42，费率年化 18%，散户 71% 做多。" `启发式`
   - "还不挤：拥挤度 +0.08，费率接近零。"
   - "人群在另一边：空头拥挤 −0.35。"
2. **光谱条**（七行，中心对齐，与 v0.1 一致，加第七行 24h 爆仓多空比）；每行右侧数字；hover/点按显示各所明细与 7 天迷你图。
3. **拥挤度仪表**（−1 到 +1）+ 30 天分位数："比过去 30 天里 87% 的时候都挤"。
4. **人群 vs 大户**一句话 + 与我仓位的关系（若有）。

第二屏：
5. **时序图**：价格 + 可叠加：拥挤度、费率、OI、散户多头、大户净仓位、爆仓柱；默认叠加拥挤度；周期 15m/1h/4h/1d；范围 1d 到 90d。
6. **分交易所表**：价格、费率（原始 / 8h / 年化）、下次结算倒计时、OI、24h 成交、散户多头；最便宜的所高亮。
7. **大户在这个币上**：多空堆叠条 + 前 10 仓位（含距强平 %）。
8. **OI 象限**卡：当前处于"价涨 OI 涨 / 价涨 OI 跌 / 价跌 OI 涨 / 价跌 OI 跌"哪一格，站内统计该格之后 24h 平均收益与样本数 `站内自验证`。
9. 子页入口：危险在哪 · 拿着多少钱 · 回放这个币。

### 3.4 危险在哪 `/coin/[symbol]/levels`

这是 Coinglass 热力图的替代，但用交易者能直接用的形式：**价格标尺**。

- 竖向价格轴，当前价在中间，范围 ±15%（可缩放）。左右两侧标记：
  - 左：**爆仓堆**（模型估算，柱长 = 估算杠杆仓位密度；`模型估算`）
  - 右：**大户强平价**（真实，来自 HL 仓位；点显示钱包与名义）
  - 右：**真实爆仓发生过的价位**（过去 24h，Gate/OKX/Binance/Bybit）
  - 中：**你的开仓价 / 止损 / 强平价**（若设置）
- 顶部答案句："上方 +3.1% 处有约 4.2 亿美元的空头爆仓堆；下方 −2.4% 处有 2 个大户合计 1.8 亿美元的多头强平价。" 附与你仓位的距离。
- 下方：多空爆仓堆合计对比、过去 24h 真实爆仓多空对比、模型假设滑块（杠杆分布权重可调，改动实时重算）。
- 热力图作为第二视图（Tab），给习惯 Coinglass 的人。

### 3.5 拿着要花多少钱 `/coin/[symbol]/cost`

- 输入：方向、金额、持有时长（默认读我的仓位）。
- 输出：每 8h、每天、期间总费率成本，六所各自的成本，"换到 X 所每天省 Y 美元"，历史 30 天该方向累计费率曲线。
- 一句话："过去 30 天做多 BTC 平均每天付 0.02%，最贵的一天 0.15%。"
- 套利提示（`启发式`）：跨所价差扣费后的年化，附执行风险说明。

### 3.6 大户在干什么 `/whales`

四个板块，每个都是"故事"，每张卡可分享成图片（带水印和链接）：
1. **事件流**（实时）：一句话一条："0x5b5d…c060 在 2,271 加空 ETH 5300 万美元，账户 1.03 亿。" 每条 1h/4h/24h 后回填涨跌颜色。筛选：币、类型、最小金额、只看关注。
2. **赌局板**：当前最大的 20 笔仓位：币、方向、名义、开仓价、距强平 %、浮盈亏、杠杆、钱包；按"距强平"排序时就是**快爆板**。
3. **认输板**：过去 24h 大户被强平与大额止损平仓（closed_pnl 为负且 ≥ 100 万美元）。
4. **今日赢家/输家**：按 24h 实现盈亏排。
- 顶部答案句："追踪的 53 个大户净空 40%，过去 24 小时净开空 2.1 亿美元，主要在 ETH。"
- 钱包主页 `/whale/[address]`：账户曲线、当前仓位、历史事件、风格标签（"高杠杆短线 / 低杠杆波段"，站内算法）、该钱包事件的历史命中率、关注与告警按钮。
- **记分板** `/scorecard`：大户开仓 / 平仓 / 翻转之后 1h/4h/24h 的顺向命中率与平均收益，按币和方向分组，滚动 30/90 天，样本数与置信区间可见。首页答案句里引用的"启发式"在这里能查到来源。

### 3.7 当时发生了什么 `/replay`

- 选币 + 选时间（或从时间线、从我的仓位的开仓时间跳入）。
- 显示那一刻的完整棱镜快照（七行 + 拥挤度）、前后 ±6 小时的价格 / 费率 / OI / 爆仓 / 大户事件叠加图、那 6 小时内的事件列表。
- "和现在比"开关：两列并排。
- 一句话复盘（自动，`启发式`）："开仓时多头拥挤 +0.45、费率年化 22%，之后 4 小时多头爆仓 6000 万美元。"
- 可保存为复盘卡片（登录），可导出图片。

### 3.8 今天做哪个币 `/find`

- 不是 30 列表格。先给**人话预设**（点一下出结果，结果每行显示币、当前价、一条迷你光谱、一句为什么入选）：
  - 空头太挤（拥挤度 < −0.3 且费率为负）
  - 多头太挤（拥挤度 > +0.3 且费率年化 > 15%）
  - 大户和散户相反（分歧 > 25 点，样本 ≥ 3 个大户）
  - OI 刚冲高（OI 24h 变化 > 15%）
  - 有人在付钱给你（负费率且跨所价差可套）
  - 大户刚翻转（过去 24h 有翻转事件）
- 高级模式：表格 + 条件组合 + 保存（登录）。
- 每个结果可"加入关注"或"设置告警"。

### 3.9 帮我盯着 `/alerts`

- 三步创建：选对象（我的仓位 / 币 / 大户 / 全市场）→ 选模板（每个模板一句人话，如"当有大户在我反方向开仓超过 500 万美元时"）→ 选渠道（Telegram 主、邮件、浏览器推送）。
- 免费：3 条 + 每日摘要；Pro：50 条实时 + Webhook。
- 消息格式：一句话 + 三个关键数字 + 一张迷你光谱图 + 深链接到"当时看"。
- 投递记录可查；一键暂停全部。

### 3.10 凭什么信你 `/method`、`/scorecard`、`/status`

- 方法：每个指标一张卡：定义、公式、来源、局限、更新频率。
- 证据库：每条"已验证"标签的数据量、期间、方法、效应大小；你的本地研究摘要明确标注样本期和"未在本站复现"。
- 记分板见 3.6。
- 状态页：各源延迟与 30 天可用率。
- 变更日志。

### 3.11 市场环境与过去 24 小时 `/coin/[symbol]/context`（币页第二个 Tab，首页有全市场版）

边界：技术分析在这里只回答"这是什么样的市场"和"大家都盯着哪里"，不给方向信号。每个判断附证据标签；你的研究已表明形态与状态过滤器不产生超额收益，所以本页所有内容都是**描述**，页面顶部有一行常驻说明。

**第一屏：四句话答案（自动生成）**

1. **状态**："4 小时级别震荡，1 天级别上行趋势。"（`启发式`）
2. **位置**："处于过去 24 小时区间的 82% 位置，距昨日高点 0.6%。"
3. **动力来源**："这波上涨由现货带动，永续溢价为负，OI 下降，属空头回补。"（`启发式`，机构视角）
4. **波动**："今日预期波动 ±2.1%（期权隐含），过去 24 小时实际 3.4%，已超预期。"

**A. 状态面板（散户最想知道：趋势还是震荡）**

| 项 | 显示 | 计算（全部免 key K 线） |
|---|---|---|
| 趋势/震荡标签 | 1h / 4h / 1d 三个标签，每个：趋势上 / 趋势下 / 震荡 / 转换中 | ADX(14) > 25 且 EMA20 与 EMA50 同向 = 趋势；ADX < 20 = 震荡；其余 = 转换中 |
| 均线堆叠 | 三个周期各一行小图标：价格在 EMA20/50/200 之上或之下 | EMA 数值 hover 可见 |
| 震荡区间 | 若为震荡：给出区间上下沿与当前位置百分比 | 过去 N 根 K 线的高低点聚类 |
| 波动状态 | 低 / 正常 / 高 / 极端 | 当前 ATR(14) 相对过去 90 天分位 |
| BTC 相关性 | "过去 7 天与 BTC 相关 0.82，Beta 1.4" | 1h 收益滚动相关与回归 |
| 状态解读 | 一句话："震荡里追突破胜率低；趋势里逆势摸顶胜率低。"（`观点`，标注来源是常识而非本站统计） | – |

**B. 关键价位（大家都盯着哪里）**

一把竖向价位表（与 3.4 的价格标尺共用组件，本页只放"人为价位"）：
- 昨日高 / 低 / 收，本周开盘，本月开盘，今日开盘（UTC 与用户时区各一）
- 日 VWAP 与 ±1σ 带；从过去 24 小时最大爆仓事件起算的锚定 VWAP
- 过去 24 小时成交量分布的 POC（成交最密集价位）与高低量节点
- 整数关口（1000 / 500 / 100 视币价）
- 24 小时区间的 0.5 位
- 每个价位标注"距当前 %"；与 3.4 的爆仓堆重叠的价位加粗并注明"爆仓堆与人为价位重合"

**C. 过去 24 小时发生了什么（数字 + 一句话）**

- 高 / 低 / 区间 % / 当前在区间的位置
- 24 小时成交量 vs 30 天日均（"放量 1.8 倍"）
- 最大 15 分钟波动（时间、幅度、当时爆仓金额）
- 三个交易时段分别的涨跌：亚洲（00–08 UTC）、欧洲（08–13）、美国（13–21）；"美盘反转"之类的一句话事实
- OI 24 小时变化与价格变化 → **OI 象限**标签（价涨 OI 涨 = 新多进场；价涨 OI 跌 = 空头回补；价跌 OI 涨 = 新空进场；价跌 OI 跌 = 多头平仓），附本站统计的该象限后 24 小时平均收益与样本数（`站内自验证`）
- 费率 24 小时变化；爆仓多空合计；大户净开仓
- 迷你时间线：把 `/missed` 里该币的事件缩成一行

**D. 动力来源（机构视角，翻成人话）**

| 项 | 显示 | 计算 |
|---|---|---|
| 现货 vs 永续 | "现货带动 / 杠杆带动"标签 + 永续溢价（标记价 − 指数价）/ 指数价 的 24 小时曲线 | Binance 现货与永续 K 线；`premiumIndex` |
| CVD | 现货 CVD 与永续 CVD 两条线叠加价格；背离时标注"价格新高但永续 CVD 未新高" | 主动买卖成交量累计（K 线 taker 买量字段） |
| 突破真假 | 当价格突破 B 中任一价位时：显示突破时 OI 变化、CVD 方向、成交量倍数三个信号，标签"三项一致 / 分歧" | 突破后 15 分钟窗口 |
| 盘口厚度 | 当前价 ±1% / ±2% 内买卖挂单美元量与比值；30 天分位（"流动性偏薄"） | Binance / Bybit / OKX L2 快照，每分钟 |
| 杠杆水平 | OI / 市值；30 天分位 | OI 合计 / CoinGecko 市值 |
| 期权定价 | 隐含日波动、本周到期最大痛点、25d skew 的"看跌溢价 / 看涨溢价"标签（仅 BTC / ETH） | Deribit |
| 基差 | 季度年化基差与费率年化并排；"基差贴水但费率为正"这类不一致标注 | 已有 |

**E. 给散户的风险换算（机构的仓位思维）**

- 输入风险预算（默认账户的 1%）与止损方式（ATR 倍数或价位）→ 输出"这笔最多开多少名义、多少杠杆"；一句话："按 1.5 倍 ATR 止损，1% 风险，这笔仓位应是账户的 4.2 倍名义，杠杆 4x 即够。"（`启发式`，公式公开）
- 若已设"我的仓位"：显示当前杠杆相对建议值的倍数，和"止损距离是 ATR 的多少倍"。

**F. 事件日历（本页底部与首页宏观条共用）**

- 今日与未来 7 天：各所资金费结算时间、Deribit 周 / 月到期（名义规模）、美国 CPI / FOMC / 非农（固定日历，手工维护 JSON）、Binance 上新 / 下架公告；每项标注距现在多久。

**首页的全市场版（首页第 5 块之后）**

- **市场环境一行**：BTC 状态标签（三个周期）+ 波动状态 + 动力来源标签。
- **广度**：前 100 币中，24 小时上涨的比例、在 EMA20 之上的比例、OI 上升的比例；三根横向进度条；一句话"山寨跟涨 / 只有 BTC 在涨"。
- **山寨 vs BTC**：等权山寨指数 24 小时相对 BTC 的表现。
- **时段热力**：过去 7 天 × 三个时段的 BTC 涨跌小格子。

**优先级**：A、B、C 进 P1（与币页同期，数据只需 K 线）；D 中现货 vs 永续、CVD、OI 象限进 P1，盘口厚度与期权进 P3；E 进 P2；F 进 P2。


### 3.12 状态词典（Market State Dictionary）

原则：**只描述状态，不给动作**。全站任何地方不出现"买入 / 卖出 / 入场 / 出场 / 加仓 / 止损位建议"。状态由公开的确定性规则计算，规则修改必须写入变更日志；每个状态的后续表现由站内记分板公开统计，用户自己判断。

**状态如何算**：三个周期（1h、4h、1d）各自判定一个状态；页面显示组合句，如"日线上涨中，4 小时健康回调，1 小时压缩"。判定用到的输入全部免 key：K 线（价格、成交量、主动买量）、OI、费率、爆仓、现货 CVD、永续溢价。参数（ATR 倍数、分位阈值等）在方法页公开。

**词典（14 个状态，分五组）**

| 组 | 状态 | 规则要点（满足即判定，冲突按顺序取先） | 通常意味着（`启发式`） |
|---|---|---|---|
| 上涨 | **上涨·推进** | EMA20 > EMA50，价格在 EMA20 之上，近 N 根创更高高点，ADX 上升 | 趋势延续中，追高风险随离均线距离增大 |
| 上涨 | **上涨·健康回调** | 上涨结构未破（价格仍在 EMA50 之上，未跌破前一个更高低点）；自高点回撤 0.5 到 2 ATR；**OI 下降**（杠杆多头在减，不是新空在开）；回调 K 线成交量低于均量；费率较高点回落；现货 CVD 未显著下行 | 杠杆在出清、现货没有在卖，结构完好 |
| 上涨 | **上涨·危险回调** | 上涨结构未破，但回调中 **OI 上升**或多头爆仓放大、成交量放大、现货 CVD 转负、费率仍然偏高 | 有人在回调里加空或多头被动加仓，回调可能演变为反转 |
| 上涨 | **上涨·过热** | 价格距 EMA20 > 2 ATR，或 RSI(14) > 75，或费率年化 > 30% 且拥挤度 > +0.4 | 人群一边倒、持仓成本高，波动放大概率上升 |
| 上涨 | **上涨·衰竭** | 价格创新高但 OI 与永续 CVD 未创新高，成交量递减，上影线增多 | 推动力减弱，但衰竭可以持续很久 |
| 下跌 | **下跌·推进** | 上涨组的镜像 | – |
| 下跌 | **下跌·健康反弹** | 下跌结构未破，反弹 0.5 到 2 ATR，OI 下降（空头回补为主），成交量缩，费率回升 | 空头在平，非新多进场 |
| 下跌 | **下跌·危险反弹** | 反弹中 OI 上升、空头爆仓放大、现货 CVD 转正 | 新多在进或空头被挤，反弹可能演变为反转 |
| 下跌 | **下跌·投降** | 单日多头爆仓超过 30 天分位 95%，费率显著为负，成交量超均量 2 倍，价格距 EMA20 < −2 ATR | 强制去杠杆事件 |
| 下跌 | **下跌·衰竭** | 新低但 OI 与 CVD 不再新低，量缩 | 卖压减弱 |
| 震荡 | **区间·上沿 / 中部 / 下沿** | ADX < 20，价格在最近 N 根形成的区间内；按位置分三档 | 区间内突破失败率高（`站内自验证` 后给出数字） |
| 震荡 | **压缩** | ATR 处于 90 天 15% 分位以下，布林带宽处于低位，OI 持续累积 | 波动率均值回归：大波动临近，方向未知 |
| 转换 | **突破·待确认** | 过去 4 根 K 线内收盘突破区间或关键价位；显示三个确认信号：OI 变化、CVD 方向、成交量倍数，并标"三项一致 / 分歧" | 真假未定 |
| 转换 | **假突破** | 突破后 4 小时内收回区间内 | 被困的一方通常成为燃料（`启发式`） |

**显示方式**

- 币页与筛选器：一个**状态芯片**，颜色只表示组（上涨绿、下跌红、震荡灰、转换黄），文字是状态名；点开显示本次判定命中的每条规则和数值（"OI 24h −6.2% ✓，回撤 1.3 ATR ✓，成交量 0.7× ✓"），让用户看到为什么。
- **状态时间带**：币页顶部一条 7 天 / 30 天的横向色带，每小时一格，显示状态历史；hover 看当时价格。
- **状态统计**（记分板的一部分）：每个状态出现次数、进入后 4h / 24h / 72h 的收益分布（中位数、分位、最大回撤），滚动 90 天，样本数与置信区间可见；全站引用"通常意味着"的地方链接到这里。
- **状态变化告警**：可订阅"当 BTC 从健康回调变为危险回调时通知我"；消息只含状态与数据，不含动作。
- **首页**：BTC 与前 10 币的状态芯片一行。

**措辞规范（法务与风控）**

- 允许："处于""转为""满足 X 条规则""过去 90 天该状态之后 24 小时中位收益 +0.4%（n=37）"。
- 禁止："建议""可以考虑""适合""机会""目标价""止损设在"。
- 每个状态解释句必须带标签；"通常意味着"一律是 `启发式`，除非记分板样本 ≥ 100 且置信区间不含零，才可升为 `站内自验证`。
- 页面顶部常驻一行："状态是描述，不是建议。"

## 4. 显示规范（所有页面）

- **答案在前**：每页第一行是一句话，20 字以内的中文或 25 词以内的英文，后跟证据标签。图表在答案之下。
- **三色**：多头绿、空头红、中性灰；拥挤度轨道用品牌渐变；不用第四种语义色。
- **数字**：等宽；金额用 K/M/B；百分比一位小数；费率四位小数；时间用用户时区。
- **卡片右上角 "i"**：定义、来源、局限、更新时间，全站统一。
- **四态**：加载骨架、正常、降级（灰色 + 最后成功时间）、错误（重试）。不显示零来冒充数据。
- **分享**：首页光谱图、大户卡片、回放卡片、币页光谱可一键生成图片，带 hlens 水印与链接。这是免费获客的主要路径。
- **手机**：底部五键；页面第一屏放得下答案句 + 一张图；表格首列固定横向滚动；图表支持手势。
- **速度**：首屏 1 秒内可读（SSR），任何交互 100 毫秒内有反馈。
- **语言**：中英双语，术语表统一（如 crowding = 拥挤度，liquidation cluster = 爆仓堆）。
