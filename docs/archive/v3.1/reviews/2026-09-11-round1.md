# 审核记录 · 第一轮（2026-09-11）

五个并行审核（Opus）：项目经理、后端架构师、前端负责人、API 规范专家、散户交易者。对象：docs v3（00–03）与 api/openapi.yaml v1.0.0。以下是每方的总体判断与被采纳的关键条目；全部条目已合并进 v3.1 文档与 openapi v1.1.0。

## 项目经理
判断：写得漂亮但不可执行；14 周对 1 人 + AI 约等于 9–15 个月工作量；P0 两个验收门依赖拿不到的历史数据；无法律页面；差异化押在非官方接口上。
采纳：路线图重排为 20 周（S0 法务与容量 → S7 发布）；状态校准 v1 只用价格类特征；句子黄金集改合成输入；S0 交付条款/隐私/免责/来源许可/18+/地域/支持邮箱/账号删除；排行榜只作候选池种子；OKX 带单榜先验证；`RiskSizer` 改纯计算器、预设改中性名、记分板与返佣隔离；分面新鲜度预算；爆仓标"下界"、级联相对阈值；记分板预注册 + FDR + 块 bootstrap；Tunnel 双连接器、静态层作降级模式、无 SLA；社群只做 TG 频道、砍微信群、TG 深链归因；商业化改为"展示免费、Pro 卖额度、等待名单 ≥ 50 再接 Stripe、返佣只做 HL"；钱包政策与 opt-out；删除"绕过地域封锁"的公开表述；SEO 一节；验收改为可判定；M15 不做；免费 VPS 回收风险。

## 后端架构师
判断：数据模型三处必然事故（压缩晚于保留、无唯一键用 COPY、无符号归一化表）；限速基本没算（逐符号 REST、深度、HL fills 超限数倍）；HA 与安全是承诺不是设计。
采纳：`instruments` 表；每表唯一键 + staging + ON CONFLICT；压缩参数与顺序；ticks 改 WS + CAGG；全市场端点；限速预算逐所计算；HL fills 走 WS 订阅 hot 200；`sentence_log` 只写变更不存文本；清算价精确公式与分档 MMR、OI 增量按 taker 净量拆方向；事件以 fills 为权威源；记分板统计修正；Telegram/Resend 限额；Stream MAXLEN/消费组/幂等键；主库放东京；HA 承诺改 RPO 5 分钟 / RTO 1 小时并含 fencing；Docker 端口绑 tailnet、Redis ACL、PG hostssl；Webhook SSRF；`CF-Connecting-IP`；pgBackRest 备份；Alembic CAGG autocommit；Redis 预序列化响应与 CF Cache Rule；`seq` 用 Redis INCR、liq 批量；多空比按 kind 分存；fixtures 需 2 年日线；运行手册补 14 条。

## 前端负责人
判断：句子"前端格式化"与契约只返回渲染字符串互斥，是会返工的头号问题；WS 无类型；四态与 URL 状态未定义；180 KB 预算不可达。
采纳：`Sentence.vars` 变量槽，前端按 locale 渲染；WS schema 入 YAML（`StreamSubscribe/StreamMessage` + `x-hlens-ws`）；`listCoins?symbols=` 批量，仓位栏走 WS；`PATCH /me/positions/{id}`、`client_id`、localStorage schema 与冲突规则；`/me/push-subscriptions`、`PUT /me`、`DELETE /me/watchlist`；分路由预算与图表懒加载、size-limit；`ModelSliders` 改重新请求；字段路径修正；`CoinSummary` 补 taker/OI 分位/爆仓拆分/状态组；`/history` fields 枚举 + venue 参数 + 大户净仓与爆仓字段；`/events` types 枚举数组；每组件四态列；URL 状态约定；八步数据流；令牌补全；PrismChart Canvas + reduced-motion + 表格视图；Satori CJK 子集与 `/og/{template}` 入契约；`EvidenceTag` 增 `insufficient`、`model_estimated`；底部五键映射；i18n 路由与数字格式按 locale；LCP 定义。

## API 规范专家
判断：不是合法的 OpenAPI 3.1（221 错误）：`nullable` 111 处、42 个响应缺 description、根 tags 写法错误；三套命名方言；静态层"子集"声明不成立；无 operationId、无 4xx、无 WS/MCP schema。
采纳：全文件改 `type: [X, "null"]`；Tag Object；每响应 description；58 个 operationId（= MCP 工具名）；标准错误响应与头；列表封套；字段名统一（`price/size/notional_usd/account_value_usd/pnl_30d_usd/roi_30d/funding_8h/funding_apr_pct/next_funding_ts/venue/symbol`）；排序键 = 字段名；`VenueFunding` 复用；`Context` 子对象具名；`prefixItems`；`x-hlens-cache` 全覆盖；`x-hlens-stage: v1.1` 标记期权与基差；`session` 与 `apiKey` 两种安全方案，创建 key 仅 session；`SnapshotFile` 独立 schema；`redocly lint` 与 `oasdiff` 入 CI。

## 散户交易者
判断：现在不会替代 Coinglass，但能成为"在 Coinglass 之前先开的那一页"，前提是分歧与我的仓位真做出来；会赶走用户的是：状态名不敢信、答案句像报数、3 个样本也给百分比、文档夸大覆盖。
采纳：样本规则（n < 10 置灰、n < 30 不给百分比）；每句必须带分位或历史频次；状态命名分级（未验证用中性名 + 常驻统计行）；"我的仓位"换三件具体的事 + 粘贴一行输入 + 直白隐私文案；价格标尺真实优先、模型灰底；首页改"今天最不正常的 3 个币"、问题卡砍到 3 张；市场环境只留四句话 + 关键价位，机构面板折叠或后移；术语气泡；告警免费 5 条含距强平，付费模板改为用户真正愿意付的三种；WhaleCard 作为主分享卡；钱包页首行命中率；回放降为"当时看"按钮；高级表格砍掉；成本折进币页一行；句子引擎上线范围缩到 5 个模板。
